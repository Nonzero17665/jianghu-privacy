## 一、我们如何收集和使用您的个人信息

### （一）游戏自身数据

本游戏没有账号、登录、支付、社交、排行榜或云存档功能。您在游戏中产生的进度、角色状态、设置等数据仅写入您的设备本地存储，用于下次启动时继续游戏。本游戏自身不会将这些数据上传到我们的服务器，我们也无法通过服务器访问、读取或收集这些数据。

### （二）广告服务

本游戏接入 TapADN 广告 SDK（由上海艾得蒽数字科技有限公司提供），用于可选的激励视频广告。广告是本游戏的附加功能，不观看广告不影响基础单机玩法。

只有您主动点击「看广告」时，本游戏才会初始化广告 SDK 并请求广告。在广告请求、展示、归因和反作弊过程中，广告 SDK 可能处理以下信息：

设备型号、操作系统版本、网络状态等设备与运行环境信息；

广告标识符等设备标识符（在系统授权和 SDK 配置允许的范围内）；

广告展示、点击、关闭、视频完成等广告交互记录；

为完成广告请求、广告归因和反作弊所需的网络与设备信息。

本游戏当前的广告配置已关闭位置、电话状态、应用列表、Android ID、OAID、MAC、BSSID、SSID、传感器等可选个人信息采集开关，不基于这些信息进行个性化推荐；广告展示仍可能使用设备型号、操作系统、网络状态等完成请求、反作弊和频次控制。若未来启用基于其他信息的个性化广告，我们会在启用前更新本政策，并在游戏内提供关闭或拒绝入口。

TapADN SDK 的合规与隐私说明请见：https://ssp.dirichlet.cn/docs/compliance/ 。

### （三）设备权限调用情况

安装包可能包含广告 SDK 所需的以下权限，实际权限以安装包清单为准：

| 权限 | 用途 |
| --- | --- |
| 网络 / 网络状态 | 请求和加载广告、检测网络是否可用 |
| 应用安装 / 包可见性 | 广告落地页安装跳转与广告反作弊所需 |

部分广告 SDK 还可能声明设备厂商的补充标识权限（如 ASUS、Soter 等），仅用于设备标识服务，不涉及通讯录、相机、麦克风、相册或精确位置。本游戏不申请上述与玩法无关的权限。

### （四）我们如何使用您的个人信息

本游戏自身不将您的游戏进度用于画像、推送或广告投放。广告 SDK 处理的上述信息仅用于广告请求、展示、归因、反作弊和效果统计；我们不会出售您的个人信息。

## 二、我们如何保存您的个人信息

本游戏自身不收集、不上传个人信息，因此不存在由我们保存的服务器端个人信息。游戏进度与设置保存在您的设备本地，保存期限由您自行决定：您可以在游戏内覆盖存档、在系统设置中清除应用数据，或直接卸载应用；卸载或清除数据后，本地存档与设置即被删除。

广告 SDK 处理的信息由其按照自身隐私与合规要求保存。具体保存期限、存储地点和删除方式，请参阅 TapADN SDK 的合规与隐私说明。

本游戏自身不向中国境外传输个人信息；广告 SDK 的数据处理与传输按其合规说明执行。

## 三、我们如何使用 Cookies 和同类技术

本游戏自身不使用 Cookies、浏览器本地存储、像素标签、埋点或跨应用、跨网站追踪技术。广告 SDK 可能使用本地存储、设备标识符或类似技术完成广告请求、频次控制、归因和反作弊；相关处理由 SDK 提供方按照其隐私说明执行。

## 四、我们如何共享、转让、公开披露您的个人信息

本游戏自身不收集个人信息，因此不会由我们向第三方共享、转让或公开披露您的个人信息。

当您主动点击「看广告」时，广告 SDK 会向 TapADN 广告平台发送广告请求及前述设备、网络和广告交互信息，用于广告投放、归因、反作弊和效果统计。该等处理由广告 SDK 提供方负责，属于您使用广告服务所必需。

应用商店、手机操作系统可能在安装、更新、分发或系统服务过程中独立处理相关信息，该等处理由相应平台依据其隐私政策负责，不属于我们向第三方共享。

我们不会出售您的个人信息，也不会将您的个人信息用于本政策未说明的目的。

如您对广告 SDK 处理的信息有查询、删除或其他请求，可通过本政策第十节的联系方式与我们联系，我们会协助您联系 SDK 提供方；您也可以直接依据 TapADN SDK 的合规与隐私说明行使相关权利。
